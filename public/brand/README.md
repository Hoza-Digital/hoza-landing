# HOZA Velocity identity

Velocity is HOZA's primary identity. It uses four clearly separated custom glyphs so the name always reads as H-O-Z-A. The wide proportions, chamfered O, and decisive Z diagonal carry the technical speed of the original option 2 wordmark. A single violet signal inside the O connects the new typography to HOZA's portal language.

## Primary assets

- `hoza-logo-velocity.svg` — preferred full-color lockup for dark surfaces
- `hoza-mark-velocity.svg` — standalone chamfered portal mark
- `hoza-app-icon-velocity.svg` — contained mark for favicons and app icons
- `hoza-logo-velocity-mono-light.svg` — one-color light lockup
- `hoza-logo-velocity-mono-dark.svg` — one-color dark lockup
- Matching PNG exports are provided for raster-only destinations

The earlier Closed Orbit files remain in the folder as a retired exploration and should not be used for new work.

## Color

- Wordmark white: `#F5F2FA`
- Signal violet: `#8B5CFF`
- Primary background: `#08050D`

Use the full-color logo on HOZA's dark interface. Use a monochrome asset when production is limited to one color or when the violet signal cannot maintain sufficient contrast.

## Spacing and minimum size

- Keep clear space around the lockup equal to the width of one vertical H stem.
- Do not render the full lockup below `104px` wide in digital layouts.
- Use the standalone mark below that threshold; its practical minimum is `16px`.
- Preserve the supplied spacing between all four letters. H and O must never touch or overlap.

## Integrity

Do not stretch, rotate, outline, shadow, glow, rearrange, or typeset the name with a substitute font. Use the supplied vector artwork so the custom geometry and letter spacing remain intact.
